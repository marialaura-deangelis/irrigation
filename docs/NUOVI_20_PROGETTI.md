# Schede tecniche dei 20 nuovi repository

Selezione aggiunta il 20 novembre 2026. Le descrizioni sono fondate sulle pagine dei repository, non su una esecuzione indipendente dei programmi.

## Reti in pressione, pompe e regolazione

### EPyT

- Repository: https://github.com/OpenWaterAnalytics/EPyT
- Scopo: Toolkit Python per EPANET: portate, pressioni, pompe, valvole e scenari idraulici.
- Pertinenza didattica: elevata
- Verifica necessaria: controllare le equazioni adottate, le condizioni al contorno, gli esempi e le versioni prima di usare i risultati per il progetto.

### EPyT-Flow

- Repository: https://github.com/WaterFutures/EPyT-Flow
- Scopo: Generazione di scenari e dati per simulazioni idrauliche di reti in pressione.
- Pertinenza didattica: elevata
- Verifica necessaria: controllare le equazioni adottate, le condizioni al contorno, gli esempi e le versioni prima di usare i risultati per il progetto.
